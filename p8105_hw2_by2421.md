Problem 1

``` r
subway = read_csv(
  "data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
  show_col_types = FALSE
) |>
  clean_names() |>
  select(
    line, station_name, station_latitude, station_longitude,
    route1:route11, entry, vending, entrance_type, ada
  ) |>
  mutate(entry = entry == "YES")

dim(subway)
```

    ## [1] 1868   19

The dataset contains information about subway entrances and exits,
including station name, line, coordinates, routes served, entry
permission, vending, entrance type, and ADA compliance. I standardized
the column names, kept the requested variables, and converted entry to a
logical variable. The cleaned dataset has 1868 rows and 19 columns. It
is not tidy yet because the routes are spread across multiple columns.
